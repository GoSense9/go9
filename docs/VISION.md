# Vision

GoSense9 aims to provide a small, auditable Go control plane for HardenedBSD/FreeBSD systems. M0 focuses only on bootstrapping process roles, local control, a constrained console, and a minimal web dashboard.

Later milestones may explore jails, PXE, clustering, 9P, WASM, an App Center, storage replication, and production PID 1 behavior.
